## 3. 必须修正的五个具体理解

### 3.1 “潜在融化”不应只用正温累积表达

Srivastava的核心过程包括负温区显著冷却、随后回暖及热交换变化，地表与空气温度还存在不同的极值时序。仅计算max(T,0)会把负温区的−25℃升至−5℃处理成同样的零贡献，损失这一过程信息。

因此，气温距平和有符号温变作为主候选；正积温保留为与本题夏季背景相关的扩展。寒冷或升温是否与本次吉隆事件相关，需由本题数据判断，不能反向套用冬季Chamoli结论。

### 3.2 论文中的温度、地温与本站观测不能互换

Srivastava的Ts为模式地表皮肤温度；Zhong的Temperature为2000—2016多年平均地温。本项目0.1m土温具有土层热惯性和不同空间位置，既不能直接替代Ts，也不能代替源区多年冻土地温。T20m−T2m与论文T2m−Ts也不是同一梯度。

### 3.3 不能把所有“长波”视为同一个测量边界

Srivastava展示OLR与GLW，但未提供足够WRF变量名/边界说明来确认OLR与本站上行长波Rlu完全同义。本站可以根据自己的四分量辐射定义构造地表净辐射和净长波；引用论文时称为相似的辐射过程分析，不称逐项复现其所有变量。

### 3.4 冰川指标有研究动机，不等于已经验证重要

Zhong因缺失过多从统计中排除了裂隙、冰川变化、速度与沉积物四组。本文献没有证明本题NC冰厚、气候态速度属于“最重要触发因素”；冰厚也不是其图2中的直接候选。现有NC无时间维，不能生成灾前加速度或2026年速度突变。

### 3.5 真实传播距离属于结果，预警输入必须事前可获得

Zhong利用灾后实际轨迹的Lreal等量解释灾害链。有助于事后分析，但如果本题未来用于预警，需改用灾前地形可确定的潜在路径、候选断面或仿真预测距离，不能把真实最终运动范围作为灾前特征。

### 4.2 关键公式与需要确认的条件

净辐射：

$$R_n=R_{sd}-R_{su}+R_{ld}-R_{lu}.$$

若每行是一个小时的平均辐射通量，完整窗口的累计能量为：

$$E_{Rn,w}=\frac{3600}{10^6}\sum_{i=1}^{w}R_{n,i}\quad[\mathrm{MJ/m^2}].$$

若记录是瞬时值，积分应明确采用何种近似，不直接当成已知精确能量；若四分量分别已经带方向符号，则必须先统一原定义再使用上式。H、LE、G、净辐射不能简单相加后称“净融化能”，还缺地表类型、储热、反射/发射性质和冰面状态等条件。

气温历史距平：

$$A_T(t)=T(t)-\operatorname{Median}\{T_{\mathrm{historical}}:\text{同期且同小时}\}.$$

对2026事件可先固定2021—2025历史资料；季节匹配窗口建议以±15天为初始设计，同时比较±7和±30天。所有这些宽度都属于待检验设置；闰日按日历规则处理，避免3月以后简单日序号错位。先构造每小时A_T，再求24小时均值。

2021年4月前无有效小时观测，2022年FLUX又有长缺口，因此历史样本数须按变量和匹配时段逐一报告。若重做历史年份预测回测，基准必须在该次训练资料内拟合，不能将验证年或未来年混入。

## 8. 指标构造之前应固定的质量规则

### 8.1 先做特征级质量检查

现有基础清洗统一了缺失值并保留原QC，没有宣称所有有限值都可信。尤其需要进一步处理：

- 2022年向下长波历史最小值约−728W/m²，不能视作正常有效地面入射长波；部分短波也有较大负值。应核查QC、其他分量与持续性后确定排除/待审规则，不能把所有负辐射一律截0，也不能一律保留用于能量累计。
- 2022年H、LE有效小时仅约全年一半；2026年LE还存在幅度很大的读数。有限值和极端真实天气都可能出现，不能仅凭大值自动删去，也不能未经检验作为灾前异常证据。
- FLUX没有供应源QC；敏感性版中保留FLUX并不等于其“QC=0”。QC=0只是一套明确的筛选假设，需比较其影响。

数据依据：`data/quality/variable_year_summary.csv`、`source_qc_hourly.csv`及清洗报告。这里只提出下一步检查需求，本次不修改已有数据。

### 8.2 按统计量分别处理缺失

| 统计量 | 初版建议 | 原因 |
|---|---|---|
| 降水、PDD、辐射能量累计 | 要求窗口完整且所需分量有效；不完整则缺失 | 未观测时段可能正好有峰值，不能按剩余小时和冒充完整累计 |
| 均值类 | 可预设至少90%有效观测作为初始规则，并与80%、100%做敏感性比较 | 90%不是文献阈值；报告覆盖率，并检查缺失是否集中于特定日夜或天气条件 |
| 极大值/极小值 | 初版完整窗口更稳妥；有缺口的结果单独标为部分窗口极值 | 部分观测最大不等于完整期间最大 |
| 两端点变化 | 两端点有效；窗口过程诊断另要求足够内部观测 | 端点差与整个过程完整性是两种要求 |
| 温度梯度、H+LE、Rn | 每个小时先要求所有参与分量同期有效，再做滚动统计 | 不能让两个变量用不同小时样本相减或相加 |

90%举例为6小时至少6个、24小时至少22个有效值，需要向上取整；仍须检查丢失位置，不能仅凭比例保证无偏。对事件附近的缺口也不特事特办降低门槛。

### 8.3 同时保留数值和元数据

每个特征至少记录：名称、原字段、单位、空间来源、观测时段、窗口及端点约定、缺失规则、有效数、QC口径、历史基准、文献依据与局限。将证据分为“原文直接分析的量”“原文过程启发的派生量”“题目与数据支持的扩展”，不把三者混在一起。

## 9. 构造之后怎样判断是否保留

本节是后续验证设计，不是本次已完成的分析。

1. 先检查单位、窗口、缺失与极端值，确认曲线来自真实有效观测。
2. 展示事件前后时序与历史同期参照，观察温度、辐射、热通量、风、湿度和土壤状态的先后关系。灾后资料只作过程对比，不进入灾前特征。
3. 检查特征组内冗余：不同降水窗口、温度距平/温变/PDD、净辐射/净长波、H/LE/H+LE、U10/u*/TKE之间都可能有关联。
4. 检查窗口、QC、历史年份和季节匹配宽度变化后，结论是否稳定。
5. 若只有单次真实灾害时刻，最多建立本次事件的关联候选与异常证据；不能把逐小时窗口当成多次独立灾害。若补足事件目录，再进行按完整事件或年份的外部验证。

文献没有替本题解决关联性目标和独立样本问题，也没有授权把事后“是否发展成灾害链”的标签变成第一问任意小时的泥石流标签。

## 10. 当前可执行的方案边界

| 项目 | 本次确定的处理 |
|---|---|
| 数据主体 | 项目内四类小时观测；无需等待运行WRF才能开始 |
| 温度策略 | 温度距平与双向变化优先，PDD作为扩展 |
| 风与湿度 | 10m风速、2mRH纳入首轮；比湿和高空风待补充 |
| 辐射策略 | 分量保留、净量和长波分别诊断；先核查异常辐射 |
| 土壤策略 | 保留本站湿润状态与变化，土温辅助解释，不冒充源区温度 |
| 热通量策略 | H/LE主候选，总量与方向性扩展；先核实符号和质量 |
| 结构指标 | 温度梯度、TKE、u*；风切变可扩展，不宣称完整边界层反演 |
