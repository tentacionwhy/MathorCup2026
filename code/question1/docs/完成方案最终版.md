## 0. 正确理解题意：先明确四个概念

第一问原题要求，基于MET、RADM、SOIL、FLUX等资料，分析**大气边界层结构、天气过程、极端气象事件与吉隆泥石流的关联性**，并给出关联性排序最高的**5个特征因素**。

下列概念不可混为一谈：

| 层级 | 它是什么 | 在本文中的作用 |
|---|---|---|
| 三个研究视角 | 大气边界层结构、天气过程、极端气象事件 | 决定论文主体按什么问题展开 |
| 物理因素组 | 温度、降水、辐射、风场、湿度、土壤水热、湍流等 | 决定最终比较哪些**不同物理含义**的因素 |
| 计算特征 | 24h均温、72h累计降水、6h平均TKE等 | 将物理因素转为可计算、可比较的指标 |
| 最终五因素 | 结合统计、时空和机制证据筛选的五项因素 | 第一问的最终交付结果；每项要有明确的代表特征 |

**三个视角不是三个互斥的特征容器。** 同一个温度特征，可以被用于天气过程分析，也可以接受极端性检验；温度垂直梯度则还可以用于边界层结构分析。论文按三个视角组织，算法按物理因素组管理指标。

**关键边界**：现有明确灾害事件数量有限，历史匹配日期不能直接视为“未发生灾害”的负样本。因此，第一问可建立“本次事件前的异常及关联证据排序”，不能仅凭异常罕见度证明物理因果或估计普适的灾害发生概率。

### 3.1 候选物理因素与特征量化方法

**本节回答**：“分析对象有哪些？怎样把原始观测转换成可比较的物理量？” **不分析**哪个因素已经最异常或最重要。

必须写：

1. 简述选取因素的文献与机理依据，并给出“三视角—因素组”的对应表；
2. 用几种统一的数学算子定义大部分特征，不逐列重复推导；
3. 对有独立物理含义的组合量给出单独公式；
4. 说明候选全集已预先定义，并交代本站与ERA5两种数据来源。

建议把以下公式放在**3.1正文**，不必将所有31列都写成展开式。

**滚动均值**（对有效、等间隔小时值，缺失窗按既定QC规则处理）：

\[
\overline X_w(t)=\frac{1}{w}\sum_{k=0}^{w-1}X(t-k).
\]

**累计量**（仅适用于各小时已经换算成相应“小时增量”的变量）：

\[
C_w(t)=\sum_{k=0}^{w-1}x(t-k).
\]

**相邻24小时均温变化**：

\[
\Delta T_{24}(t)=\overline T_{24}(t)-\overline T_{24}(t-24).
\]

**净辐射**（四分量均须同一时段有效）：

\[
R_n(t)=R_{sd}(t)-R_{su}(t)+R_{ld}(t)-R_{lu}(t).
\]

若小时值单位为W/m²且表示小时平均通量，累计净辐射能量为：

\[
E_{R,w}(t)=0.0036\sum_{k=0}^{w-1}R_n(t-k)\quad (\mathrm{MJ/m^2}).
\]

**近地层温度梯度**：

\[
G_T(t)=\frac{T_{20\,\mathrm m}(t)-T_{2\,\mathrm m}(t)}{18\,\mathrm m}.
\]

解释清楚：上述温度梯度是近地层的**分层代理量**，不是完整边界层高度；累计净辐射不是源区实际融冰热量。

**其他特征**：如6h平均TKE、6h平均摩擦速度、24h土壤含水率变化、风速极值、ERA5由风矢量计算的风速等，采用上面的通用算子并在特征字典中说明计算口径。任何新增特征都应同时登记公式、单位、窗口、来源、QC要求和解释边界。

### 3.2 大气边界层结构特征分析

**本节只回答**：“灾害前，观测站近地层的垂直结构和湍流交换呈现什么状态、怎样变化？”

**实际计算和展示**：

- 用MET的1、2、4、10、20m观测生成温度、湿度、风速的垂直廓线；至少比较白天与夜间，必要时再分灾前典型时段；
- 计算并画出2—20m温度梯度与代表性风切变的灾前时序；
- 利用FLUX的TKE、\(u_*\)、感热和潜热通量分析近地层湍流交换变化，注重与温度梯度、风场变化的同步或时滞；
- 可以提供廓线与历史同期的简要对照，但**不在此全面计算极端罕见度排名**。

**建议图**：一张多面板图——温湿风垂直廓线 + 梯度/TKE灾前变化；最多再配一张必要的热通量子图。

**文字应回答**：是否出现可识别的层结变化？湍流交换增强或减弱？这种变化持续多久？数据是否存在缺测或高度相关性？

**解释边界**：1—20m只能反映**近地层**，不能凭此宣称测出了完整大气边界层高度。观测站远离源区，不能把塔站层结视为源区的直接测量。

**3.2完成判据**：至少有一组能够直接回答“结构如何变化”的图和文字结论；即使这些指标没有进入前五，这节仍然成立。

### 3.3 灾前天气过程与地气水热响应

**本节只回答**：“在事件发生前，温度、降水、辐射和陆面响应是如何随时间演化的？”

**按物理过程，而非数据文件组织**：

**A. 热状态与能量交换过程**：气温、24h温变、净辐射、感热、潜热。分析灾前30天总体背景、灾前7天的主要转折、最后24h的变化；讨论变量先后关系，不直接宣称某个热异常造成冰崩。

**B. 水分输入与陆面响应过程**：降水、空气湿度、不同深度土壤温度与含水率；判断是否存在降水—含水变化、冷暖—冻融相关的可观察过程；不能把本站土壤含水直接解释为源区冰川基底水压。

**C. 源区天气背景**：对可比变量，用ERA5-Land固定源区参考格点及邻域展示对应的温度、降水和能量过程；与塔站比较**各自历史异常方向和时间形态**，避免把两处不同海拔、不同下垫面的绝对温度直接作同址验证。

**建议图**：两组多面板时序图——“热状态与能量过程”“降水与地表水热响应”；必要时将源区ERA5作为其中一组图的对照线或单独小面板。

**文字应回答**：观察到了怎样的实际过程？异常是在事件前还是事件后？有哪些变量呈先后变化？本站与源区的过程是否一致？如果不一致，清楚报告。

**本节不做**：给31列各自排一个名次；重复写滚动均值公式；依据过程图确定冰崩的精确触发时刻。

**3.3完成判据**：形成可读的灾前环境过程描述，不是四套源数据的流水账。

### 3.4 极端气象条件与历史异常识别

**本节回答**：“哪些环境状态或过程在历史同季节背景下罕见？哪些并不极端？”

**背景构造**：以2021—2025年每年8月26日±15天（即8月11日至9月10日）同钟点为主历史匹配锚点，名义上5×31=155个；按同一滚动窗口计算每个候选特征的历史分布。记录实际有效数，跨年不拼窗，缺失不填0。±7天和±30天用于后续敏感性。

**基本评价**：对每列的事件前特征值\(X_j^*\)，计算其相对于历史同季节分布的百分位或经验尾部比例\(r_j\)；可用

\[
A_j=-\log_{10}(r_j)
\]

表示罕见度。温度变化、通量等在主方案中可能采用双侧；降水等可根据事前声明采用上尾。请在计算前固定方向，不根据结果临时选择有利的一侧。

补充异常持续时长与时间演化，区分偶发单小时尖峰、持续偏离及累计异常；需要说明仅有五年历史基线，且滚动窗口高度相关，经验尾部比例不是严格的独立样本p值。

**重点区分术语**：强降水、异常高低温、强风等可讨论“极端气象现象”；土壤水分、净辐射、感热通量的极值则应称“环境/水热指标异常”，不全部混称“极端天气事件”。如果没有发生某种极端过程，要报告“未发现”，不能为了符合题意制造结论。

**建议图**：一张多面板历史背景带（中位数、5%—95%区间、2026事件前轨迹），辅以小型异常分位数汇总表。

**3.4完成判据**：有明确历史参照、有超阈值/持续性结果、有极端与非极端的区分；避免提前宣布最终前五因素。

### 3.5 灾害关联证据评价与五因素筛选

**本节回答**：“在已观测到的结构、过程和异常中，哪五个不同的物理因素最值得与本次灾害联系起来？为什么？”

这里是**第一问的主成果**，需要把前面三个视角汇总，但不要将三个视角分配名额（如边界层必须选2项）：题目没有这样的要求。

**推荐两阶段流程**：

1. **数值初排**：31列先计算历史罕见度，归入10个因素组；为避免某组拥有多个时间窗口/数据来源而天然“更容易挑到极端值”，用历史伪事件重复同样挑选程序，对组最大异常进行校准；在历史参照中检查高度冗余的指标。
2. **关联证据审核**：逐组检查异常发生时间是否合理、源区及邻域是否支持、该指标是否反映与冰岩崩—碎屑流—泥石流机制相容的过程，以及QC与方法设置变化后是否稳定。统计分数不能单独被写成“致灾关联强度”或“因果贡献率”。

**当前实施方案的较完整筛选程序**（可简述于正文，详细方法放代码或补充表）：

- 5个历史年份按“3年建立参考分布＋2年校准”进行\(\binom53=10\)种划分，记录每组排名的变化；这些不是10次独立灾害验证；
- 让历史伪事件也执行同样的“组内挑最大异常—组间比较—前五筛选”，防止多候选挑选优势；检验时避免伪事件参与自己的参考/校准样本，留块和排除重叠窗口；
- 物理上相同的因素组最多保留一个代表；跨组Spearman\(|\rho|\ge0.9\)仅作为冗余检查提示，结合物理意义判断；
- 按事先固定的校准罕见度及稳定性规则提出排名，再报告证据不足及对规则敏感的因素；不随意设计“物理机制得3分、异常得5分”的加权排名。

若扩展第二轮候选（如PDD、冷却—回暖、H+LE等），须明确是探索性扩展池并重新执行同样筛选，不能看到本次事件数值后只增添看起来最显著的指标。

## 3. 实施流程：以数据交付物驱动论文写作

下列顺序是**运行工作顺序**，不要求与论文三个视角的呈现顺序完全一致。

| 步骤 | 计算操作 | 产出文件或表 | 主要对应章节 | 验收点 |
|---|---|---|---|---|
| 0. 口径核查 | 核对站点UTC+8与ERA5 UTC、时间标记起止、ERA5累积量、通量方向、源区参考网格、QC | `analysis_protocol.md`、口径/质量表 | 公共数据章及3.1脚注 | 不利用未来信息；小时累计转换正确 |
| 1. 特征工程 | 读现有清洗数据；批量构造14类、31列指标及覆盖率标记 | `feature_catalog.csv`、`features_hourly.csv` | 3.1 | 各列定义/单位/窗口可追溯，缺失不填0 |
| 2. 结构分析 | 计算廓线、梯度、湍流过程 | 廓线与湍流图 | 3.2 | 能回答“近地层结构如何变化” |
| 3. 过程分析 | 生成灾前30天/7天/24h气温、降水、辐射、水热和ERA5过程 | 2组过程图、过程观察表 | 3.3 | 有时序证据；本站和源区不混同 |
| 4. 历史对照 | 生成155个名义锚点，计算历史百分位/罕见度、持续性 | `matched_anchors.csv`、`anomaly_evidence.csv` | 3.4 | 同季节/钟点/窗口；报告有效数 |
| 5. 综合筛选 | 31列→10组；历史伪事件校准、冗余与敏感性检查；核对时空和机制 | `group_rankings.csv`、`top5_evidence.csv` | 3.5 | 五因素有明确证据及局限 |
| 6. 写作与压缩 | 按3.1—3.5填数值、图、图注和段落，删除重复解释 | 第3章LaTeX正文 | 全章 | 约5—5.5页、原题四项任务均可定位 |

### 实施时必须避免的错误

- **时间泄漏**：把灾后观测纳入“事件前”特征；把题设口岸受灾10:30直接认作源区冰崩启动时间。主分析保守使用参考时刻之前已经完成的小时窗口，并对截点作敏感性检查。
- **累计量处理错误**：ERA5-Land不同下载通道的降水/辐射/热通量可能分别是小时增量和日内累计，不能统一再差分。先依现有下载核验及产品说明处理。
- **来源混淆**：ERA5网格不是现场测量，当前下载ERA5区域不覆盖塔站；不可宣称完成本站—ERA5同址验证。塔站约65km外，仅提供区域近地层背景。
- **标签伪造**：155个同期窗口不是155次独立非灾害样本；ERA5相邻网格也不是多个独立事件。
- **选择偏差**：不能先扫描几百个候选窗口、时间截点和格点，再只报告最异常结果。候选全集、方向和主窗口先固定；扩展后全套历史比较重做。
- **解释跃迁**：异常大≠关联强≠导致灾害；通量异常≠冰川实际融化量；土壤湿度变化≠冰下孔隙水压变化。

## 5. 论文写作时的段落模板（写作提示，不是伪造结果）

以下不是可以直接替代计算结果的结论，只规定段落应包含的信息。

**3.1段落结构**：从冰崩—泥石流灾害链与题目给定数据出发，引出物理因素组；说明选取依据；列统一算子及核心组合公式；说明候选总量与各数据来源。

**3.2段落结构**：先报告实际廓线和梯度特征 → 再描述灾前变化与湍流交换 → 最后说明该站的近地层观测范围及源区代表性限制。

**3.3段落结构**：依时间顺序描述主要热力与水分过程 → 展示源区ERA5同类变量的背景 → 总结观测一致和不一致之处。不得把未观测到的冰体内部过程写成已经发生。

**3.4段落结构**：交代历史匹配规则 → 报告主要特征的分位、方向及持续性 → 明确哪些气象极端事件有证据、哪些没有 → 提醒五年基线局限。

**3.5段落结构**：简述组内校准与去冗余规则 → 给出10组完整比较 → 用表列出前五 → 逐项简述历史异常、时间/空间及机制证据 → 解释哪些因数据缺口仍不能作因果推断。

\section{灾前大气环境特征与泥石流关联因素分析}
